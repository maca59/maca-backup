# Privacy Policy — maca BackUp

**Document version 1.2**

This Privacy Policy describes how **maca BackUp** handles data when the plugin is used on your WordPress site. The product name is maca BackUp (not “Pro”). Provider: Maca Development.

## 1. Backup data

Backups may include files and database content from your site (themes, plugins, uploads, posts, users, settings, and similar). That data stays under **your control**: on your server and/or in cloud accounts you configure. Maca Development does not receive or host backup archives.

## 2. Credentials you enter

Storage credentials (FTP passwords, API tokens, S3 keys, OAuth tokens, and similar) are stored in your WordPress database or options as configured by the plugin. They are used only to transfer backups to destinations you choose. Keep your WordPress admin and hosting secure. Maca Development does not collect these credentials for hosting backups.

## 3. Install lifecycle events

On activation, deactivation, and uninstall the plugin sends your site URL, plugin version, WordPress version, PHP version, and locale to api.maca.se so we can improve the plugin and count active installations. If you submit deactivation feedback, your selected reason and optional comment are included. Backup archives and database contents are never uploaded.

## 4. maca Hub

maca Hub is always connected. The plugin may send limited operational metadata to api.maca.se—for example site URL, plugin version, WordPress/PHP versions, locale, and backup history entries (type, date/time, size, status)—for multi-site monitoring and product statistics. Backup file contents and database dumps are never uploaded.

## 5. Support form and contact

If you use the in-plugin support form on the Support tab, the plugin may send your name, email address, subject, message, site URL, plugin version, and optional system information to Maca Development so we can reply. If you email [support@maca.se](mailto:support@maca.se), we process the information you provide (and any diagnostics you choose to share) to respond to your request.

## 6. Your obligations

You are the controller of personal data contained in your site backups. You are responsible for retention settings, restore testing, destination security, and ensuring you have a lawful basis to process and store that data.

## 7. Third parties

Remote storage providers you connect (for example Google, Dropbox, Microsoft, FTP hosts, or S3-compatible services) process data under their own terms. Maca Development is not responsible for those services.
